# Documentation Archive

This area is historical context, not current product or API documentation.
Verify every path, count, status, and recommendation against code before use.

- `analysis/`: dated audits and defect investigations.
- `reviews/`: dated code and pipeline reviews.
- `plans/`: implementation plans and design drafts.
- `todo/`: resolved TODO-board snapshots.
- Root files: superseded research and phase snapshots.

Do not add new current contracts here. Move a completed or superseded draft
here only after preserving its date and original context.
