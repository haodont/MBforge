# Archived Markush Extensions

These three files are archived non-runtime, experimental, and currently unconnected Markush extensions:

- `markush_advanced.py`
- `extract_markush_definitions.py`
- `markush_events.py`

Active Markush review and enumeration remain in `src/`. Activity-related code is intentionally retained in its existing locations and is not part of this archive.

The archive is reversible. Restore these files by reversing the three moves from this directory back to their original `src/mbforge/` paths.

Reverse each move below to restore the original path:

```text
src/mbforge/chem/markush_advanced.py -> docs/archive/code/markush/markush_advanced.py
src/mbforge/pipeline/extract_markush_definitions.py -> docs/archive/code/markush/extract_markush_definitions.py
src/mbforge/core/markush_events.py -> docs/archive/code/markush/markush_events.py
```
