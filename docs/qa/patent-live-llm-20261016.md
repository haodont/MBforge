## 尚未通过的关键点

1. **复杂分档表运行稳定性。** CN121270515A拿到包含重复表头、`++++`与缺失编号的表格后，没有提交答案，最终触及总预算。100秒请求设置未在这一长等待中及时终止，单次请求超时语义需要单独排查。
2. **候选结构质量与实体歧义。** CN120329282A的候选目录中，“1”同时对应 `*N1CCC1` 片段和完整结构；CN121270515A的“3”也有不同候选结构字符串。自动关联不再用最后一个候选覆盖前者，但本次没有得到已验证的标签消歧答案。
3. **Markush与具体分子的隔离。** 两篇的标签缺口都包含Markush识别载荷，且候选匹配可能受载荷内数字影响。本轮未完成这些缺口，不能据此宣称通式已被正确识别为实体或正确隔离。
4. **引用合法不等于科学正确。** 工具接受提交证明协议与引用范围有效；本轮四条读数另做了行列核对。其他字段及结构本身仍需要独立验证。
