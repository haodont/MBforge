# Pi 升级、研究提示词与 Tavily 接入验收（2026-10-13）

本记录对应研究工具升级，独立于 `research-workbench-20261013.md` 的上一轮 UI 验收。

## 实现范围

- Pi 由弃用的 `@mariozechner/pi-coding-agent` / `pi-ai` 0.73.1 迁移为 `@earendil-works` 1.2.0，版本在 `agent/package.json` 与锁文件中固定；实际环境 Python 3.12.13、Node 24.19.0。
- 共用会话工厂改用内存 `ModelRuntime`、凭据存储与模型目录，关闭模型目录联网刷新；保留应用指定的提示词、工具集合和研究 JSONL 路径。未开启原生文件、shell、项目/用户插件自动加载。
- 官方 `@tavily/pi-extension@0.1.2` 原生加载，复用其 provider 调用；MBForge 仅限制参数、输出、来源范围和每轮额度，适配设置文件密钥并清除返回内容/错误中的密钥。
- `search_library` 搜索 SQL SourceEvidence：关键词以 AND 组合，字面匹配，不把 `%`/`_` 当通配符；有限分页、2000 字符片段、截断标记与文档/页码/证据编号。仅覆盖已提取证据，不宣称覆盖未提取 PDF、完整全文或全部笔记。
- 共用研究提示词指导本地检索、原文下钻、缺口判定、联网检索及来源核查，要求保留测定与物种语义。专利独立会话不加载联网工具。
- 设置页复用原有控件，新增 Tavily 开关和密钥输入；默认关闭，保存后下一条消息生效。中英文工具名称与会话联网状态提示已接通；开关与密钥输入具有可读标签。

## 使用与回退

在“设置 → AI 模型 → LLM → 联网研究 · Tavily”保存 API Key 并开启开关。关闭开关后下一条消息只使用本地工具；不会删除资料库或会话历史。依赖迁移未修改用户运行数据。整个工作区含上一轮未提交修改，回退本轮应按文件/区块选择，不对整个工作区执行重置。

## 未验收与已知限制

- 未使用真实 LLM 或 Tavily 密钥；未进行新的浏览器视觉验收；自动联调不能证明科学答案质量。
- 私密内容不外传规则在研究提示词中约束；公共 URL 和工具参数有程序校验，但关键词的公开性仍依赖模型判断。
- 官方扩展的中止机制停止等待，底层请求可能继续运行或消耗额度；异常大响应可能先写入上游临时文件，然后才被 MBForge 截断返回给模型。
- 查询为简单关键词检索，无向量检索或全文排名；有限片段必须按原文核查，检索无命中不能解释为知识不存在。
- 已确认的既有 Windows 对接测试 `test_udp_command_and_pose_parsing` 使用无法作为 Win32 程序执行的测试替身，触发 `WinError 193`，本轮不修改对接引擎。
