03

各路线实现细节

每条路线的关键做法与局限

规则 / 符号管线

OSRA → ChemSchematicResolver → ReactionDataExtractor

输入图先灰度化、去噪、二值化；箭头靠直线检测加「钩子侧像素更多」判据，分子靠像素聚类找「键多、尺寸合适」的团块，再叠加 OCR 与符号规则组装反应。每步可靠但错误逐级累积，换画风就不灵。

可解释误差累积泛化弱

端到端序列生成

RxnScribe（JCIM 2023 · MIT）

把整个任务压成「下一个 token 预测」：ViT 编码图像，自回归解码器逐 token 输出，每个分子 = 量化后的 4 个坐标 bin + 角色 token（reactant / product / reagent / arrow）+ 反应编号，推理时反量化拼回结构。仅 1,378 张真实图训练即达 soft F1 80.0%，开箱可用。

开箱可用坐标离散化复杂图弱

LVLM 微调

RxnIM（Chem Sci 2025 · 开源）

第一个为反应图解析训练的 MLLM。先用数据生成器从 Pistachio 反应库渲染大规模合成反应图（单行/多行/分支/环形四种排版），再三阶段训练：合成图检测预训练 → 组分识别与条件提取 → 统一指令微调。输出仍是 BROS 式 JSON，但合成分布和真实文献有偏移。

合成数据规模化域偏移7B 级算力

视觉提示 + 字幕生成

RxnCaption（CVPR 2026 · 未发布）

核心洞察：LVLM 不擅长预测绝对坐标。先用 SOTA 检测器 MolYOLO 框出每个分子并画上索引（BIVP），再把带标注的图发给 LVLM 让它描述「框 1 是反应物，箭头指向框 2，条件是 A/B」——坐标已画在图上，模型只做语义推理。配合 11k 真实数据成为当前 SOTA。

SOTA依赖外部检测器未开源

标识符提示 + 可验证 RL

RxnID（2026 · 未发布）

用反应图里天然存在的化合物编号（1a、2b）作为视觉提示（IdtVP）激活 VLM 预训练时的化学知识，零样本即强；再用可验证奖励的强化学习（Re3-DAPO）直接优化反应级 soft-match 指标，比纯监督微调更稳。专门验证了 1950–90 年代扫描文献。

零样本强RL 优化指标未开源

通用 MLLM 零样本

GPT-4o / Claude / Gemini（商用 API）

把反应图直接丢给通用多模态大模型提问。MERMaid 等工业管线采用「RxnScribe 识别分子 + GPT-4o 抽其他参数」的混合。灵活、零训练，但输出不可控、坐标不可靠，且专利数据不能外传，本地保密场景不适用。

零训练不可控数据外传风险

文档级组合式

OpenChemIE（开源）/ MolMole / MERMaid

OpenChemIE 用多个 AI 模型协作完成 OCSR 与反应解析；MolMole 的 ViReact 直接从整页文档图像端到端提取反应（RxnScribe 架构 + 后处理），跳过「先检测反应区域」；MERMaid 做图分割 + RxnScribe 分子 + 大模型参数抽取。可作为整体架构参考。

文档级端到端组合灵活实现复杂

专利文本侧抽取

SureChEMBL / ChEMU / LLM 管线

与图像解析互补的维度：SureChEMBL 从美国专利文本挖掘出 100 万+ 反应；ChEMU 2020 提供约 2 万条专利反应标注；近年工作用段落级 IOB2 标注定位反应段落，再经 LLM 抽取实体、IUPAC→SMILES 转换与原子映射验证。条件、收率、投料量大量在正文里。

补全条件/收率与图像解析互补依赖文本质量
04

评测口径与数据集

比较数字前先对齐协议

评测协议

  • soft-match F1主流口径：判断预测反应是否为真阳性时忽略文本内容、把条件并入反应物、分子框按 IoU 匹配——容忍 OCR 文本错误，主要考结构拓扑
  • exact-match更严：文本、角色、坐标全部精确一致才算命中
  • RxnBench单图 QA（1,525 题 / 305 方案）+ 全文档 QA（108 篇），考感知与跨模态推理
  • ReactBenchChemReaction 1,618 道 QA，四维：空间定位 / 拓扑抽取 / 通路追踪 / 结构拓扑推理

数据集

  • RxnDP（RxnScribe）1,378 张真实论文反应图，规模小但真实
  • RxnIM 合成集Pistachio 驱动渲染，大规模但存在域偏移
  • RxnCaption-11k10,112 训练 + 400 验证、24,716 个反应、四类布局均衡，当前标杆
  • RxnID 历史集1950s–90s 扫描文献 200 图，单行/多行/树/环四类拓扑
  • 专利文本语料SureChEMBL 100 万+ 反应；ChEMU 约 2 万片段（IOB2 标注）

ChemLayout M8 选型结论

RxnScribe 打底→ RxnIM 对照升级→ 文本侧抽取补条件/收率→ RxnCaption / RxnID 发布后评估

主架构为 M2 检测反应区域 → M8 裁剪块解析，与「检测 + 解析」思路同构，检测器已自备（MolDetv2-FT）。开源约束下：RxnScribe（MIT）打底，对中等复杂度专利反应图够用且可商用；RxnIM 作对照（开源权重、效果更强，但 7B 级算力与合成域偏移需权衡）；专利文本侧抽取作为 Phase 3 补充通道，从正文段落补全条件、收率、投料量并与图像结果合并；RxnCaption / RxnID 未发布，若落地即优先评估；自建 BIVP 复现（本地开源 VLM + 自标注）是开源可达的 SOTA 路线，需要训练投入，放到 Phase 3。ViMore、GPT-4o 等闭源方案不纳入依赖。
