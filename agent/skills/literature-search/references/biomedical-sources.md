# Biomedical source guide

- **PubMed** is a bibliographic index. A PubMed result or abstract is not proof that full text was read.
- **PubMed Central (PMC)** hosts a subset of full-text articles. Confirm that the fetched page is the article version being cited.
- **Europe PMC** provides biomedical records and links to available abstracts or full text. A general web search that finds a Europe PMC page is discovery, not a reproducible Europe PMC API query.
- **Crossref** can help verify DOI metadata. Do not infer study findings from metadata alone.
- Prefer the publisher's article page or an openly available repository copy for source text. Keep preprints distinct from later peer-reviewed versions while noting a verified relationship.

MBForge's current public-search mode uses Tavily web discovery and page extraction. It does not query these databases through their dedicated APIs, apply complete database pagination, or provide systematic-review coverage.
