# Citation and evidence rules

- A search result supports only that the search service returned a candidate URL and snippet. Cite it as a discovery lead, not as checked article content.
- After `web_fetch`, cite the fetched source URL and limit claims to the text actually returned. Mark inaccessible or truncated content.
- Verify title, authors, year and DOI/PMID against a source page when available. A DOI string alone does not verify a paper's findings.
- Normalize identifiers for comparison, but do not silently merge records when title, version, or metadata conflict. Keep preprints and published versions linked only when the source establishes the relationship.
- Include the retrieval date for information that can change. State when a citation field could not be verified.
- Do not call an ordinary web search a systematic review or claim complete coverage. Report the query concepts and meaningful coverage limits when they affect the answer.
